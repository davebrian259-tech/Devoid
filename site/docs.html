Using Devoid

Devoid pays a list of people in one shielded Zcash transaction. This page covers everything you need to use it: creating a wallet, sending a batch, reading the review, and running it yourself.

Getting started

Open the web wallet on any phone or computer. Choose one of three kinds of wallet:

  • Mainnet holds real ZEC. You tick a box to confirm this before the wallet is created. Start with small amounts.
  • Testnet uses free coins from a faucet. Nothing on it has value.
  • Demo runs on a simulated chain with play money, so you can try every screen without funds.

Pick a passphrase, then write down the 24-word recovery phrase on paper and confirm it. The passphrase encrypts your keys in this browser; the recovery phrase restores the wallet in the desktop app if this browser's data is ever lost.

To receive ZEC, open Receive and share your shielded address or a payment request with the amount filled in.

Sending a batch

  1. Open Send. Add people one by one, paste a list, import a CSV file, or pick from your contacts and saved lists.
  2. Devoid checks every row as you type: the wrong network, duplicates, missing amounts, and addresses it cannot read.
  3. Watch the totals: what everyone gets, the network fee, and what you will have left.
  4. Press Review payment, check the review screen, enter your passphrase and confirm.
  5. Follow progress in Activity. Each transaction shows as pending until it is mined.

Up to 25 people go in each transaction, and a list can hold up to 2,000. Longer lists are sent as several transactions, in order, and you get a receipt with every transaction ID.

The list format

One recipient per line. A header row is optional; the columns are address, amount, memo and label.

address,amount,memo,label
u1examplefirstaddress…,1.25,October design work,Ada
u1examplesecondaddress…,0.80,Docs and translations,Grace
  • Amount is in ZEC (TAZ on testnet), up to eight decimal places.
  • Memo is optional, up to 512 bytes, and is encrypted with the payment. Transparent addresses cannot receive memos.
  • Label is optional and stays on your device; it is never sent.

Tools on the Send screen can give everyone the same amount or split a total evenly, to the zatoshi.

The review screen

Nothing is signed until you have seen the review. It shows the total, which pools the money comes from, the network, the exact fee, and a privacy report on what the chain will see.

  • Paying a transparent address, or moving money between shielded pools, makes part of the payment public. Devoid asks you to tick an acknowledgement before it will send.
  • A fingerprint ties the reviewed payment to the signed one. If anything changes in between, the send is refused.
  • Hide how many people you are paying is optional. It pads a transaction to 5, 10 or 25 payment slots so the output count does not show the real number, for one action's fee per extra slot.

Fees

Zcash fees follow ZIP 317: 5,000 zatoshis (0.00005 ZEC) per logical action, with a minimum of two, and the change output counts as one. Paying 3 people costs 0.0002 ZEC; paying 25 costs 0.0013 ZEC. The review always shows the engine's exact quote, which can be higher if the wallet has to spend many small notes.

Signing in again, and other devices

  • Your wallet stays in this browser. Coming back needs no sign-in; only signing a payment asks for the passphrase.
  • After you sign, you can stay unlocked in that tab for 15 minutes. The passphrase is held in memory only.
  • Passkey: in Settings, a passkey can unlock the wallet with your face, fingerprint or device PIN instead of the passphrase, where your device supports it.
  • Wallet file: download an encrypted copy in Settings, then choose “Open a wallet file” in any other browser and enter your passphrase.
  • Install: add Devoid to your home screen from the browser menu. It opens in its own window and works offline.

Running it yourself

The desktop app runs the same engine natively, on Linux, macOS, or Windows through WSL. It adds Tor or your own SOCKS5 proxy, and restoring from a recovery phrase.

# get the code
git clone https://github.com/davebrian259-tech/Devoid.git
cd Devoid

# try it on the simulated chain
node server/index.mjs --demo

# real Zcash: build the engine (Rust 1.88+), then run
npm run engine:build
node server/index.mjs

The server prints a private link; open it in your browser. For developers:

Questions

Does Devoid ever hold my funds? No. It is non-custodial: your keys are created and kept on your device, encrypted with your passphrase.

Why does the web wallet never ask for a recovery phrase? So that no one is ever trained to type one into a website. To use a wallet elsewhere, use the wallet file, or restore the phrase in the desktop app.

What does the server see? The lightwalletd server sees your IP address and the transactions you broadcast. Shielded transactions hide recipients, amounts and memos from it. Read the privacy policy for the full picture.

A payment says “Expired”. It was never mined, so nothing was spent. Send it again.
