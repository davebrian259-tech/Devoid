How it works

From a spreadsheet to one signature.

  1. 1

    Bring your list

    Paste rows, import a CSV, or pick people from your contacts and saved lists. Devoid checks every row as you type: the wrong network, duplicates, missing amounts, addresses it cannot read.

  2. 2

    See what the chain will see

    Before you sign you get the total, the fee, what you have left, and a privacy report. Paying a transparent address, or moving money between pools, needs your explicit OK.

  3. 3

    Sign once

    Up to 25 people go in each shielded transaction. Longer lists go out in order, each checked against what you reviewed. You get a receipt with every transaction ID.

Features

Everything a payout needs, nothing it doesn’t.

Batch payments

CSV import with address, amount, memo and label columns. Give everyone the same amount, or split a total evenly to the zatoshi.

Live totals

Recipient count, total, estimated fee and the balance you will have left, updated as you edit. Short of funds? It says why.

Contacts and lists

An address book checked against your network, and reusable lists for payroll, grants and DAO payouts.

Payment requests

ZIP 321 links and QR codes with the amount and an encrypted memo filled in, so the payer cannot get it wrong.

Activity and receipts

Pending, confirmed and expired payments, grouped by day and exportable to CSV. If a long batch stops halfway, the receipt shows who was paid.

Balances behind bars

Amounts sit behind redaction bars until you choose to show them, which is handy on a screen share.

Privacy and security

Built so nothing leaks by accident.

Keys stay on your machine

The recovery phrase is encrypted with age. Your passphrase unlocks it for one signature at a time and is never stored.

A local-only server

The wallet listens on 127.0.0.1 behind a one-time token, checks Host and Origin, and serves a strict content security policy.

What you review is what you sign

A fingerprint ties the reviewed proposal to the signed one. If anything changes in between, the send is refused.

No trackers, no accounts

No analytics and no third-party scripts. Fonts and icons ship with the app; the only server it talks to is the Zcash node you choose.

Your route to the chain

Connect directly, through the built-in Tor client, or through your own SOCKS5 proxy.

Visible when it matters

Testnet and mainnet look different on every screen, and the simulated demo engine is always labelled as such.

Get started

Try it in a minute.

The demo runs on a simulated chain: nothing to install but Node 20. Build the Rust engine when you want real Zcash.

# get the code
git clone https://github.com/davebrian259-tech/Devoid.git
cd Devoid

# try it on the simulated chain
node server/index.mjs --demo

# real Zcash: build the engine (Rust 1.88+), then run
npm run engine:build
node server/index.mjs

Linux, macOS, or Windows through WSL. The server prints a private link; open it in your browser.
